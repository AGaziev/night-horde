# Спрайты для «Ночной орды»

Ты рисуешь ассеты для браузерной кооп-игры в жанре «выживание против орды» (вид сверху, canvas 2D).
Работай ТОЛЬКО в этой папке (`sprites/`). Код игры (`../app/`) не трогай и не читай без нужды.
Используй встроенную генерацию изображений, затем Python/PIL для нарезки, прозрачности и сборки.

## Стиль
Мрачная ночная сказка, пиксель-арт (чёткие пиксели, ограниченная палитра ~24 цвета, тёмный контур 1 px),
вид сверху в 3/4, персонажи смотрят ВПРАВО (игра отражает по горизонтали). Читаемые силуэты на тёмно-зелёной
ночной земле (#1b2420). Оригинальный дизайн, никаких отсылок к существующим играм.

## Что нужно
Каждая сущность — PNG-лента кадров по горизонтали, прозрачный фон, одинаковый размер клетки.

Герои (клетка 96×96, 4 кадра ходьбы + 1 кадр «пал»): плащ/накидка НЕЙТРАЛЬНО-СВЕТЛО-СЕРЫЙ — игра перекрашивает
его в цвет игрока. Для каждого героя дополнительно `<id>_mask.png` той же геометрии: белым — пиксели плаща, остальное прозрачно.
- knight — Страж: крепкий воин с клинком и щитом
- witch — Ведьма: шляпа, посох с искрой
- ranger — Следопыт: капюшон, лёгкий, метательные ножи на поясе
- herald — Звонарь: монах-поддержка с колоколом
- smith — Кузнец: массивный танк с молотом, фартук
- stormcaller — Заклинательница бурь: хрупкая, развевающиеся волосы, молнии в руках
- alchemist — Алхимик: маска-клюв, склянки на поясе

Враги (клетка 64×64, 4 кадра анимации):
- bat — Тень (летучая тень-мышь), ghoul — Упырь, wisp — Огонёк (блуждающий огонёк, светится),
  skel — Костяк (скелет), brute — Громила (клетка 96×96), spitter — Плевун (плюётся кислотой),
  bloater — Пузырь (раздутый, взрывается)

Боссы (клетка 192×192, 6 кадров: 4 движение + 2 «замах/телеграф атаки»):
- boss — Владыка ночи (финальный, корона, плащ-тьма)
- brood — Матерь роя (призывает рой)
- ram — Рогач (бронированный рогатый, рывки)
- gunner — Костяной органист (орган из костей, стреляет кольцом)
- twin — Двуликий (двуглавый; отдельно `twinhalf` клетка 128×128 — одна половина после разделения)

Снаряды (клетка 32×32, 2–4 кадра): bolt (искра), knife (нож), sickle (серп), icedisc (ледяной диск), spear (копьё),
hostile (вражеская кислотная капля). Направление снаряда — вправо.

Земля: `ground.png` 256×256 бесшовный тайл (трава/мох/камни, очень тёмный, низкий контраст, не мешает читать врагов),
2–3 декора `prop_*.png` (надгробие, пень, грибы), клетка 64×64.

## Выход
- Все PNG в `sprites/out/`.
- `sprites/out/manifest.json`: `{ "<id>": { "file", "cell": [w,h], "frames", "fps", "anchor": [x,y] (центр ног/тени, в пикселях клетки),
  "bodyRadius": <радиус тела в пикселях клетки>, "mask"?: "<file>", "attackFrames"?: [4,5] } }`.
  Игра будет масштабировать спрайт так, что bodyRadius совпадёт с игровым радиусом: Тень r=10, Огонёк 8, Упырь 14, Костяк 13,
  Громила 22, Плевун 12, Пузырь 13, Владыка 40, Матерь 44, Рогач 38, Органист 36, Двуликий 40, половина 28, герой 14.
- `sprites/out/preview.png` — контактный лист всех спрайтов на фоне `ground.png` для проверки глазами.
- Без тени под персонажем (игра рисует тень сама). Края чистые, без ореола от фона.
- Итоговый размер всех PNG ≤ 3 МБ.

В конце напиши в `sprites/REPORT.md`: что сделано, что не вышло, какие спрайты слабые и стоит перегенерировать.
