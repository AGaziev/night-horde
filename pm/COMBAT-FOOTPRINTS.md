# Снаряды и взмахи (#45)

Baseline: `515062bedf3083689cc6f0648490b1e848daf1c4`, Node24.22.1. Локальная изолированная сцена, без сетевой потери; desktop1280×800, touch390×844. Браузер Chromium с `--mute-audio`. Воспроизведение изображения: `node pm/combat-screens.mjs` при статических серверах baseline:4632/candidate:4631.

Подтверждённые несовпадения:

1. Страж/Клинок: сервер наносит урон мгновенно прямоугольником `x=0..range, y=±width/2`, вправо/влево в мировых координатах в момент атаки. Старый crescent был сдвинут +10px и расширен +6px: внешняя кромка выступала на16px. Все220мс после мгновенного урона изображение следовало за текущим героем. При движении +35px через120мс видимый клинок проходил через заведомо непоражённую цель. Скриншоты `baseline-{desktop,mobile}-combat.png` фиксируют жёлтую фактическую рамку и красную miss-цель.
2. Снаряд врага: проверялась только новая позиция каждого тика. Воспроизведение `x=-60→60` за1/30с через героя x=0 оставляло100HP вместо90; два движущихся объекта также могли пересечься без попадания. Это диагностический стресс случай, не утверждение, что все обычные скорости спиттера туннелируют. Радиусы 7px для обычного снаряда и12px для снайперского шара не уменьшены. Радиус героя14px сохранён.

Изменение: событие slash передаёт точную мировую точку и время удара; fade остаётся на месте. Тонкая рамка совпадает с реальной областью, crescent ограничен рамкой. Это послеобраз уже произошедшего попадания, а не220мс активного оружия. Снаряды используют относительное движение двух кругов и первый момент пересечения, включая перемещение героя/рывок; end-event привязан к моменту попадания. Клиент больше не продлевает уже попавший hostile до искусственного минимального времени жизни. Свечение/хвост косметические; физическое ядро явно обведено.

Регрессии: оба направления, касание/граница и ближний промах, неподвижная цель, пересечение движущихся путей, неизменные радиусы, фиксированная точка slash. Red `footprint-red.log`, green `combat-footprint-test.js`; клиентский кодек проверяется отдельно. Скриншоты реального renderer не заменяют независимый живой матч с задержкой: root выполняет сетевую/продуктовую проверку интегрированного кандидата.

Эта отдельная ветка реализует только #45 наmain dca4c4a. Диспетчер связок и их уровни, поддержка и контроль остаются из main. Пакетные результаты общей ветки не являются приёмкой отдельного кандидата.
