# Сырые результаты сим-сверки баланса для PR #33 (Issue #23)

Ревизии: base `515062b` (main) и head `b4727c2`. 10 ячеек: `human` на 1–4 игроков и `smart` соло, в режимах «Обед» и «Ночь», по 60 сидов на ячейку и ревизию. Всего 1200 попыток.

- `attempts.jsonl` — одна строка на попытку: ревизия, режим, число игроков, бот, сид, полный `completion`, исход, время, падения.
- `raw.tgz` — полный вывод каждой попытки (`raw2/<rev>-<mode>-<n>-<bot>-<seed>.out`).
- `jobs.txt` — список заданий, `run-one.sh` — запуск одной попытки, `sum2.mjs` — сводка, `table.md` — итоговая таблица.

Ветка только для доказательств, в `main` не сливается.
