# Баланс PR #33 (Issue #23): main против кандидата

Ветка только для доказательств, не сливается.

- **main:** `dca4c4ac25954ae2bd85db27ea7634d68ab9039e`.
- **Кандидат:** серверный код `0ec426b57d822fa0180a99a0faf299e1b8c48b00`. Он совпадает с итоговым head `005e8e6`: последующие коммиты `b5384a6` и `005e8e6` меняют только клиентский `app/public/js/game.js`, тест и `DESIGN.md`. Симулятор клиентский код не загружает.
- **Симулятор:** `pm/run-sim.mjs` кандидата для обеих ревизий, `APP=<ревизия>/app`. Каталог `pm/` в main и кандидате не различается.
- **Среда:** Node v24.18.0, macOS (Darwin 25.5), 8 параллельных процессов.

## Попытки

Одна попытка:

```
APP=<rev>/app MODE=<lunch|night> K0=<seed> node --random-seed=<seed> pm/run-sim.mjs <players> 1 <human|smart>
```

Seed задаёт и `--random-seed`, и `K0`, то есть ротацию героев. Состав героев записан в `attempts*.jsonl`.

- **Основная матрица:** `jobs.txt`, seeds 1–60. Ячейки: `human` на 1–4 игроков и `smart` соло, оба режима. Получается 10 ячеек × 60 попыток × 2 ревизии = 1200 попыток.
- **Дополнительная серия:** `jobs-extra.txt`, seeds 61–200, те же ячейки, 2800 попыток. Учитывается отдельно, основная матрица не меняется.

## Файлы

- `raw.tgz`, `raw-extra.tgz` — полный вывод каждой попытки, включая `completion` и лог забега. Контрольные суммы — в `SHA256SUMS`.
- `attempts.jsonl`, `attempts-extra.jsonl` — по строке на каждую запланированную попытку: `completion`, исход, герои, падения и их причины, урон Трубача и гарнизона, оружие к середине забега, урон по боссам, финал.
- `table.md` — основная матрица; `table-extra.md` — дополнительная серия; `table-combined.md` — справочная сводка seeds 1–200.
- `run-one.sh`, `run-extra.sh` — запуск; `sum.mjs`, `combined.mjs` — сводка; `run.log` — коды выхода всех 4000 запусков.

Попытка считается терминальной при `completion.terminal === true`, `state === 'over'` и `finishCalls === 1`. Нетерминальных попыток и ошибок нет: 0 из 4000.

Как пересчитать:

```
tar xzf raw.tgz && tar xzf raw-extra.tgz && node sum.mjs && SET=extra node sum.mjs && node combined.mjs
```
