## Git
Любые операции с Git выполняй без отдельного согласования: ветки, коммиты, пуш, PR, ребейз, слияние в свою ветку, теги.
Нельзя только принудительный пуш (`--force`, `-f`, `--force-with-lease`, `+ветка`). Если без него не обойтись — спроси владельца. Запрет дополнительно проверяет хук `.claude/hooks/deny-force-push.mjs`.
