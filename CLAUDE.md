# Правила для Claude в «Ночной орде»

## Git
Любые операции с Git выполняй без отдельного согласования: ветки, коммиты, пуш, PR, ребейз, слияние в свою ветку, теги.
Нельзя только принудительный пуш (`--force`, `-f`, `--force-with-lease`, `+ветка`). Если без него не обойтись — спроси владельца.
Слияние PR в `main` — по правилам `README.md` и `.codex/project-team/WORKFLOW.md`.
