## Git
Любые операции с Git выполняй без отдельного согласования: ветки, коммиты, пуш, PR, ребейз, слияние в свою ветку, теги.
Нельзя только принудительный пуш (`--force`, `-f`, `--force-with-lease`, `+ветка`). Если без него не обойтись — спроси владельца. Запрет дополнительно проверяет хук `.claude/hooks/deny-force-push.mjs`.

## Служебные изменения
Для релизов, документации, регламентов и служебной инфраструктуры отдельный PR не нужен: следуй [разграничению в WORKFLOW](.codex/project-team/WORKFLOW.md#продуктовые-и-служебные-изменения). Прямой push в `main` выполняй только по явному назначению AGaziev или CEO; иначе передай им подготовленный коммит и результаты проверок. Это не даёт права обходить продуктовый PR или сливать его.

## Слияние
PR в `main` сливает только CEO в Codex. Claude не сливает PR в `main` никогда, даже после READY и по прямой просьбе слить: сообщи, что PR готов, и передай его CEO.
