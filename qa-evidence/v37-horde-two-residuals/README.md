## 1. Удержание только пакетов позиции

Коммит `f60e119`: интервал больше200мс считается устаревшим. Он не накапливает движение задним числом, а получает бюджет только текущего серверного такта. Обычный джиттер в пределах интервала, текущий slow, ACK и однократное расходование бюджета сохраняются; повтор пакета/resync не выдаёт бонус. Изменение ограничено Horde.

Новые регрессии сначала получили **3RED**, затем **5/5PASS**; вместе с прежними review-controls —14/14. Независимая собственная оснастка через настоящий loopback WS → native Hub/Room → snapshot codec → Game сравнила старый e727 с новым кодом:

| Подготовленный конечный сценарий | Старый e727 | Новый кандидат |
|---|---|---|
| Пропуск толькоpos1,1с, открытыйWS/ping | скачок165 | 5,5ед., повтор/resync бонуса не дают |
| Оплаченная стая в665, затем тот же ход150ед/с | герой465, бойцов0, возврат оплаты | герой305,5, бойцов12, возврата нет; обычный контроль300/12 |
| Текущее охлаждение и объявленный взрыв | ход135,3, HP140 — незаслуженный уход | ход4,51, HP132, как в обычном контроле |

Честное движение,120мс джиттера, повторный пакет, ACK, переподключение и обычный PvE проходят отдельными контролями. В первой независимой сцене удержание проверено также по1177мс wall-clock при живом ping. Сценарии оплаты используют native покупку/очередь/появление; взрыв имеет явно подготовленные состояние и геометрию. Это адресные воспроизведения, не оценка частоты манипуляции или полный живой матч.

## 2. Трубач после отталкивания Оберегом

Коммит `b11b149`: `HordeMode.nativeLanes()` использует `e.aimX ?? e.x` / `e.aimY ?? e.y`, как настоящий `sniperTick`. Нулевые координаты сохранены; fallback при отсутствующем прицеле совпадает с native залпом. `windT` и исходный дедлайн не продлеваются.

Новый тест проводит оплату пачки Трубачей → native прицел → первый key → заряд/поглощение ОберегомI и реальное отталкивание60ед. → Hub rejoin/welcome → native encoded key → Game → настоящий залп и урон. Старый код восстанавливал все5полос из(0,−60), стрелял из(0,0) и наносил9,555HP герою вне полос. Новый код показывает тот же фактический залп из сохранённой(0,0); оставшиеся0,7/0,5с и deadline162,9 сохраняются при повторном восстановлении. No-displace и nullish/zero-origin контроли проходят.
