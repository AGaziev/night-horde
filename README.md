# Ночная орда

Кооперативный онлайн-выживач до 8 игроков для Битрикс24 Vibecode.
Прод: https://app-0fdbcfb656d3.vibecode.bitrix24.tech (вход через Битрикс24).

## Где что
- `app/` — игра: сервер на Node 24 (`app/server/`), клиент (`app/public/`), общие данные (`app/public/shared/content.js`). Устройство — `app/DESIGN.md`.
- `pm/` — роадмап (`ROADMAP.md`), разборы живых забегов (`PLAYTESTS.md`), отчёты баланса (`balance-v*.md`), симулятор (`run-sim.mjs`).
- `changelog/` — тексты ченджлогов по версиям.
- `e2e/delta-prod.mjs` — проверка прода после выкладки.

## Запуск и тесты
```bash
cd app && npm ci
node server/server.js            # http://localhost:3000
for t in server/*-test.js; do node "$t"; done
```

## Правила совместной работы
- Работаем через ветки и pull request в `main`; `main` = то, что выкладывается.
- Тег `vN` = версия, которая стоит или стояла на проде. `GAME_VERSION` в `content.js` поднимаем на каждую выкладку и не занимаем чужие номера.
- **Перед выкладкой** сверить, что на проде стоит последний тег из `main` (`GET /api/busy` → поле `v`), и что никто не играет (`playing: 0`). Выкладка мимо `main` затирает чужую работу — так 11.11 потерялись с прода v25–v26 (восстановлены веткой `dev2-v25-v26`).
- При выкладке обязательно `env.VIBE_APP_KEY` (ключ приложения) — иначе выключится сохранение прогресса. Ключи и токены в репозиторий не кладём (`.env` в `.gitignore`).
- Проверки в браузере — без звука.
